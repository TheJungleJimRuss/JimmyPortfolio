# PortfolioSite

A dual-identity portfolio (Dev + Drone) entered through a shared landing page.

## Pages

**Gateway**:
The landing page where the visitor picks a pathway (Dev or Drone).
_Avoid_: Home, landing, splash

**Dev portfolio**:
The Dev pathway's page, entered through the intro sequence.
_Avoid_: Dev site, dev page

## Hero

**Hero name**:
The "JIMMY RUSS" identity mark, shown as a 3D mesh on the Gateway and as text on the Dev portfolio.
_Avoid_: Logo, title, headline

**Stacked name**:
The Hero name laid out on two lines, JIMMY over RUSS, always used on the Dev portfolio and on portrait or narrow viewports on the Gateway.
_Avoid_: Mobile name, vertical name

**Single-line name**:
The Hero name laid out on one line, used on landscape and wide viewports.
_Avoid_: Desktop name

## Projects

**Desktop**:
The Dev portfolio's surface after the Intro sequence: an OS-like desktop with icons, windows and a taskbar, where the Hero name sits.
_Avoid_: Home screen, OS, dashboard

**Taskbar**:
The bar along the bottom of the Desktop that lists open windows and holds the exit to the Gateway.
_Avoid_: Dock, nav, footer

**Hero window**:
The Desktop window that holds the Hero name; it is open when the visitor arrives.
_Avoid_: Splash window, intro window

**File Explorer**:
The Desktop window that lists the projects, with a sidebar and breadcrumbs.
_Avoid_: Project grid, file browser, OS UI

**Project window**:
The Desktop window that one project opens into, holding its Project stage and write-up.
_Avoid_: Detail view, project page, modal

**Project stage**:
The 16:9 area of a Project window that shows the project itself, through whichever medium that project uses (live demo, video or gallery).
_Avoid_: Viewport, demo window, canvas

**About window**:
The Desktop window that holds the owner's bio and Stack.
_Avoid_: About page, bio modal

**Stack**:
The named groups of tools and skills shown in the About window.
_Avoid_: Skills grid, tech list

**Contact window**:
The Desktop window that holds the ways to reach the owner.
_Avoid_: Contact page, contact form

**Screensaver**:
What the Desktop shows after the visitor has been idle for a while: the Hero name's letters drift apart over black until the visitor returns.
_Avoid_: Idle mode, sleep, attract mode

## Intro

**Intro sequence**:
The Dev portfolio's entry: Boot shell, outline trace, then hero materialization.
_Avoid_: Loader, splash

**Boot shell**:
The bare full-screen terminal that opens the Intro sequence and waits for the visitor's input.
_Avoid_: Boot log, terminal overlay, loader

**Outline trace**:
The laser stroke that draws the Desktop's lines, ending with the Hero name's outline, before the hero materializes.
_Avoid_: Laser animation, draw-on

**Layout lock**:
The rule that the Desktop and the Hero name keep the layout chosen at the start of the Intro sequence until the hero has materialized, even if the viewport rotates.
_Avoid_: Orientation freeze

## Copy

**Slot**:
A marked place on the Dev portfolio that holds text the owner writes; it shows its `[ ... ]` marker until filled, and an optional slot left empty does not show at all.
_Avoid_: Placeholder, field, copy block
