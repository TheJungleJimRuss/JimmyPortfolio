# 02: Oscilloscope saver

**What to build:** A single beam traces slowly morphing Lissajous figures (frequency ratio and phase drift over time); earlier frames fade like phosphor persistence via a translucent black fill each frame. It is a pure, seeded `SaverMotion` plus a 2D-canvas `SaverRenderer` drawn in the visitor's Phosphor color, registered with one line in the saver layer, so choosing it in the Settings panel (or Random landing on it) shows it. Under reduced motion it runs at about a tenth of the pace with fades instead of cuts. Any input ends it with the layer's plain fade.
